# 0.0.1 public release preparation

Date: 2026-08-01

## Scope

Prepared the current shared working tree for a future public npm `0.0.1` preview.
No GitHub repository, remote, commit, push, npm publication, landing-page code,
source behavior, fixture/corpus content, evaluation result, or `.env` file was
changed.

## Edits

- `package.json`
  - Set `version` to `0.0.1`.
  - Added future public GitHub metadata: `repository`, `homepage`, and `bugs` for
    `https://github.com/elielaloum/tssift`.
  - Added discovery keywords and `publishConfig.access: "public"`.
  - Added `prepack: "bun run build"`, so `npm pack` builds before packaging.
  - Added `prepublishOnly` gates: typecheck, full test suite, fixture
    verification, and non-writing `bunx biome ci`. No provenance setting was
    added, so an authenticated local publish is not made CI-dependent.
  - Kept the peer range and zero runtime dependency model unchanged.
- `bun.lock`
  - Aligned the root workspace package version with `0.0.1`.
- `README.md`
  - Added public English documentation for the CLI, its flags and exit codes,
    behavior boundaries, platform/runtime constraints, Yarn PnP invocation, MIT
    license, planned public URLs, and bounded frozen-corpus evaluation evidence.
  - The evidence claim is deliberately restricted to the `cx/gpt-5.6-terra`
    frozen-corpus run: 115,052 to 47,284 tokens (approximately 59% fewer), five
    deep cascades, 25 runs per arm, and false starts 10/25 to 5/25. It names
    `shape-tag-renamed` as the 100%-false-start counterexample and links to
    `EVAL.md` for method and raw tables.

## Verification

All commands were run from the repository using the pinned mise toolchain:

- `rtk mise exec -- bun install --frozen-lockfile` — passed; 53 installs checked,
  no changes.
- `rtk mise exec -- bun run typecheck` — passed.
- `rtk mise exec -- bun run build` — passed.
- `mise exec -- bun run test` — passed; **464 tests** (an earlier note in this
  plan said 470; the measured count is 464). Re-verified on 2026-08-01. Under a
  loaded machine the full suite can trip vitest's 5 s per-test timeout on
  `test/cli.test.ts › --all restores every diagnostic`, which spawns real `tsc`
  programs; the file passes in 5 s when run alone. Flake, not a regression.
- `rtk mise exec -- bun run fixtures:verify` — passed; 44 fixture/compiler checks.
- `rtk mise exec -- bunx biome ci` — passed; 44 files checked, no fixes applied.
- `rtk mise exec -- npm pack --dry-run --json` — passed. Its `prepack` lifecycle
  executed the TypeScript build.
- `rtk mise exec -- npm run prepublishOnly` — passed all future publish gates.
- A real packed `tssift-0.0.1.tgz` was installed into a temporary minimal project
  with `typescript@5.9.3`. `npx --no-install tssift --project tsconfig.json`
  returned exit `1`, printed `root: .`, and reported `TS2339` for the intentional
  broken property access; stderr was empty.
- The tarball inventory was inspected. It contains `LICENSE`, `README.md`,
  `package.json`, and the `dist/` build artifacts only; no `.env`, Git metadata,
  `node_modules`, fixtures, corpus, or project/evaluation documentation shipped.
